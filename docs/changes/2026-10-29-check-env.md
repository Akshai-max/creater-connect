# Production environment check (`npm run check-env`)

**Date:** 2026-10-29
**Files:** `lib/env-check.ts`, `scripts/check-env.ts`, `package.json`, `tests/session.test.ts`

## Why
Most production problems in this app are configuration: a missing password, an open webhook, test mode off, a localhost tracking URL. Each one is easy to miss, so they're now checked in one command.

## What it checks
It treats the file as production (`NODE_ENV=production`) and prints **names only, never values**.

**Blocking** (exit code 1):
- `DATABASE_URL`, `APP_PASSWORD`, `SENDER_NAME`, `SENDER_ROLE` and `SENDER_COMPANY` are missing.

**Warnings:**
- `APP_PASSWORD` is under 12 characters.
- `SENDER_POSTAL_ADDRESS` is missing (email pitches are rejected without it).
- `CRON_SECRET`, `ENGINE_WEBHOOK_SECRET` and `AGENT_WEBHOOK_SECRET` are missing or short.
- `YOUTUBE_API_KEY` is missing.
- Only one of the two Instagram values is set.
- `APP_BASE_URL` isn't a public https URL.
- `OUTREACH_MODE=live`.
- `SEED_TEST_ALLOWLIST` is empty in test mode.
- Only one of `RESEND_API_KEY` and `OUTREACH_FROM_EMAIL` is set.
- The AI agent provider is missing its key, or Ollama points at localhost.
- `APIFY_DISCOVERY` is enabled.

```bash
npm run check-env                          # checks .env.local
npm run check-env -- --file .env.production
```
